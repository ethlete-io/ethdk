# A new product starts with one real screen in finished moods

In the tomflix clean-slate run the agent opened with a layout round: grey kit boxes for where search, navigation and
films sit, every frame only a header and a box "Seite". The human (German, verbatim): "also ich als mensch wäre hier nun
lost. das sieht maximal hässlich aus. das ist die falsche herangehensweise. wir könnenn nicht einfach mit so technischen
dingen wie menü stukturen starten. das ist doch mist. was weiß ich wie das menu aussehen soll." The human stopped
wireframes on 2026-10-29; the design skill every product repo gets still taught a wireframe round.

1. **One real screen, two or three moods** (recommendation accepted: "q4ok"): the agent first draws one real screen of the
   product (for tomflix the overview) in two or three finished moods, each with real colours, real type and real content
   from the product's data. The human picks a mood.
2. **Structure is the agent's call.** Menu, navigation and layout are decided by the agent and shown only inside the
   finished screen; the human comments when something bothers them. A question about mood or models goes at most as one
   side sentence that blocks nothing.
3. **No wireframe round** in the design guidance product repos get.
4. **A fresh run tests it** ("q5ok"): the running tomflix run stops. After the design guidance changes, the human starts
   a fresh clean-slate run with the same customer description.
