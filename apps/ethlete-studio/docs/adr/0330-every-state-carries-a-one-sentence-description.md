# Every state carries a one-sentence description

On a part canvas with many states the human said: "man weiß gerne mal gar nicht worauf man überhaupt schauen soll",
and "wir werden nicht drum rum kommen auch eine beschreibung pro zustand zu zeigen. oder alternativ unsere alte sticky
note funktion". Offered (A) a required description on each state in the part, shown under the frame title, or (B)
free sticky notes on the canvas; the human answered "q1ok" to A.

Each state in a part declares one sentence: what it shows and what to check. A part with a state without it does not
build. Studio shows the sentence under each frame title. No sticky notes; free remarks stay comment pins.
