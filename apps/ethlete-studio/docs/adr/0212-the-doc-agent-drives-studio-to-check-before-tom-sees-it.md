# The doc agent drives Studio to check before Tom sees it

Tom: "während ich afk bin darfst du studio bei bedarf auch bedienen und davon screenshots machen falls du dir was
ansehen willst. ich denke mal sowas hätte die 4 sketches ohne meine aufregung gefunden." The doc agent may open and
operate the running Studio app and take screenshots of it whenever it wants to see something, not only through a
builder's `design shot`. It uses this to do step (3) of ADR 0211 itself: before a sketch or a pick reaches Tom, the doc
agent opens it in Studio and checks that the view shows a real choice.
