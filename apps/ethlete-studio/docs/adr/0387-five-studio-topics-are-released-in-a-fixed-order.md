# Five Studio topics are released in a fixed order

A product topic of list A starts only after the human set its order. No order was set, so the builder saw no startable
row once the old tool rows were done or stale, and stopped in the morning. The doc agent proposed six topics in order;
the human (German, verbatim): "q1ok aber die merge ansicht existiert schon gar nicht mehr". The merge view topic is
dropped, because that view no longer exists.

The released order:

1. A26 Studio menu, rest: the Settings, Keyboard shortcuts and About Studio dialogs and the Help target.
2. A19 Inbox: real users instead of "Du", the "interrupted" state, the real error message.
3. A27 Server status: reload, "stale", restart, stop, and the checkout scan.
4. A6 Quick switch in the rail: logo or two letters, with a tooltip.
5. A18 Comment pins also on merged sketches.

Where a topic has no merged draft, the builder sketches its own recommendation and merges it; no pick goes to the
human. The large topics (motion editor, design editor, Git in Studio, code import) each need a grill round first and
are not released.
