# A sent comment shows its pin at once, and Esc leaves comment mode

Three questions on the Studio comment button, each answered with the recommendation. The human: "q2ok q3ok q4ok".

- A sent comment shows its pin on the canvas right away, whether the Inbox is open or not. Until now the pin appeared
  only while the Inbox was open.
- While the Inbox section is open there is no comment button. New comments start on the canvas; the Inbox is for
  reading and answering.
- Esc with no open draft leaves comment mode. With a draft open, Esc first discards the draft.
