# Several variants share one change crop

With several variant columns, the change crop is the union of the change boxes of all variants, so it shows every
change. The reason text names each variant's reason on its own line when the variants differ, and keeps one line
when they share one reason or there is one variant (finding 881; at first it showed the first variant only). The human was asked "Soll das erst einmal so bleiben?" with the recommendation yes, and
answered "q2ok".
