# A sketch rule problem reads "Sketch-Regel verletzt"

When a variant of a ready sketch breaks a static design rule (for example an unknown utility class), Studio shows an
open point of the kind `sketch-problem`. Its chip reads "Sketch-Regel verletzt: <rule>", for example "Sketch-Regel
verletzt: UTILITY-CSS". The human: "q3ok".
