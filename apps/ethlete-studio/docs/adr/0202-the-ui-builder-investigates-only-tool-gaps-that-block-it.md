# The UI builder investigates only tool gaps that block it

Tom: "das ist alles echt noch viel zu langsam" about the UI builder, which had one UI item committed. It had spent its
time on tool investigations (the cause of the shell-main CONTROL-STATE hits, the gate gap behind them). The UI builder
investigates a tool gap only when it blocks its current UI item. Every other gap goes to the doc agent in one sentence,
and the tool builder investigates and fixes it. Tom: "q2ok" (option c, recommended).
