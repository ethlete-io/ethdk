# The 90 s e2e goal counts on the desk PC, and every machine stays as fast as possible

The goal "under 90 s over 3 runs" for the Studio e2e step is measured on the desk PC (117-127 s on 8 workers on
2026-11-09). The Mac (420-520 s on 3 workers) reports its time but does not gate the goal. The goal is a limit, not a
place to stop: the e2e step gets as fast as possible on every machine, and this holds in general, not only for this
item. The human: "Q1a trotzdem dollte gelten as fast as possible. Das gilt generell."
