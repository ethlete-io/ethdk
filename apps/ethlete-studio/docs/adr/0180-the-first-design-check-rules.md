# The first design check rules

Hard-coded colour (hex and colour functions outside foundations, a `var()` fallback too); copy of a component (a
component class named in element or page CSS or markup without importing it); motion (`requestAnimationFrame`,
`setInterval`); a relative import out of the part's own folder.
