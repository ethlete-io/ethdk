# Select and form field get a ghost variant

Select and form field get a public input `variant: 'default' | 'ghost'`. `ghost` draws no border and no background,
for toolbars and table cells; `default` stays as today. An app sets the look through this input, never by
overriding the component's styles.

The human, asked to choose between the new input or per-app style overrides, with the recommendation "the input":
"q2ok".
