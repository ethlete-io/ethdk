# A sketch of an SDK base part merges into the base

A sketch made from an SDK base part (`.ethlete/design/sdk/...`) merges into the base by default; a product override
needs an explicit `sketch new --override`. The studio copy of `components/button` from `e304eb3d0` goes away.
