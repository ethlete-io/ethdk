# A reference informs a design round, it is not a template

Option 1, as a rule in the `ethlete-design-exploration` skill: before a reference-led round is shown, the agent states
the problem each reference solves, the principle it takes, and how each variant differs in concept, then reviews the
variants beside the reference for literal copies. No fixed visual rubric.
