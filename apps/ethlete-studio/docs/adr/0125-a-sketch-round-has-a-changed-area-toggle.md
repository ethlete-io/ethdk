# A sketch round has a Changed area toggle

Small changes vanished in full-page sketch columns. The round header gets a "Changed area" toggle that shows the
shared crop at the same scale for Current and every variant, with a thumbnail outline of where it sits; it is on by
default when the crop is less than half of the frame area.
