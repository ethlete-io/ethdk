## High findings

- `components-lib-scan/cascader-dropzone.md` - Arrow/Home/End roving focus lands on disabled nodes, and a disabled node is a native `<button disabled>` that cannot take focus.
- `components-lib-scan/notification-tabs-scrollable-button.md` - The tab bar handles every `keydown` that bubbles to its host, so arrow keys, Home and End typed into an input inside an `et-tab-group` panel are cancelled and move focus to a tab.
- `components-lib-scan/notification-tabs-scrollable-button.md` - `provideNotificationManager({ defaultDuration: { error: 8000 } })` replaces the whole `defaultDuration` map, because the config merge is shallow, so `success` and `info` stop auto-dismissing.
- `components-lib-scan/overlay.md` - `OverlayDirective` does not close its overlay on destroy.
- `components-lib-scan/rte-headless.md` - `outdentListItem` moves the item after its parent `<li>` but leaves the siblings that follow it in the old sublist, so the content changes order.
- `components-lib-scan/rte-headless.md` - `insertNormalizedHtml` inserts multi-block content after the caret's top-level block, not at the caret.
- `components-lib-scan/rte.md` - `createRichTextEditorTriggerWithQuery` shows the results of the previous search text.
- `components-lib-scan/scheduler.md` - Every "does this appointment touch this day" test treats the end as inclusive, so an appointment that ends at 00:00 also lands on the next day.
- `components-lib-scan/select.md` - Closed typeahead on a multi select toggles an option through `selection.select`.
- `components-lib-scan/table-core.md` - `restoreState()` sets `columnOrder` to the restored keys only, so a column declared after the state was stored is not in the order and `orderedColumns` drops it.
- `timetrack-lib-scan/integrations.md` - The backfill parses each host read with no `resume`, so a Codex log longer than one read loses `sessionId`, `cwd` and `model` after the first chunk.
- `timetrack-lib-scan/jira-tempo-model.md` - Preview, coverage and the agent delete read Tempo for the calendar date only, but proposals and the ledger follow the configured day boundary.
- `timetrack-lib-scan/stream-ticket-settings.md` - `targetOf` keys a rule by `repoPath@branch` and ignores `workPath`.
- `bracket-lib-scan.md` - A swiss round past the last record round, with undrawn matches, goes into the fallback group `undrawn`, but `drawSwissMan` parses every group id as `wins-losses` and throws ET3408 on it.
- `query-devtools-lib-scan.md` - The `Ctrl/Cmd + Alt + Q` matcher treats AltGr as Ctrl+Alt.
- `contentful-types-lib-scan.md` - An embedded entry or asset that is missing from `includes` throws, and the whole document stops rendering.
- `cli-agent-rules-lib-scan.md` - `repair` sends `GITLAB_TOKEN` to whatever host the `origin` URL names.
- `cdk-security-scan.md` - `paginate()` reads `window.location.href` and `PaginationHeadService._updateHead()` reads `window.location.origin` with no platform guard.
