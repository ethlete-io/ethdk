`et design sketch round <layer>/<name> <round> --title … --note …` edits a round after it was created, and `sketch list` shows the rounds of each sketch. `sketch variant --round` prints the notes of the previous round, an unknown `sketch` or `design` command prints an error and the usage, and the `sketch report` usage and the "more than one product" error name `--product`. The usage prefix now names a package script that builds and runs the cli, so it works in this repo.
