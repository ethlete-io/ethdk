# Icon Button — Design Specification

Square icon-only button. Default variant is `transparent` (unlike the Surface Button which defaults to `filled`).

---

## Anatomy

```
[ icon ]                      ← sized per `size`
[ loader overlay ]            ← absolute, fades in during loading state
```

- **Icon slot** — `[etIcon]` attribute selector; sized per `size` (see Sizes)
- **Loader** — absolutely positioned spinner that replaces the icon visually

## CSS custom properties (override API)

These tokens adjust appearance without touching internals. The generic `--et-button-*` tokens (font-weight, cursor, disabled opacity, border-width) apply here too — see the Surface Button spec.

> **Note:** the diameter and icon size are set **per size** by the component, in a `:where([data-size='…'])` block on the button itself. So the override has to land on the button element (one class in the selector is enough to win), not on an ancestor — and it applies to all sizes unless you scope it with a size selector too. `--et-icon-button-border-radius` is the exception: the component never declares it, so an ancestor context can set it.

## Focus ring

Rendered by `FocusRingDirective` — a separate visual layer outside the button's own box model. Shown only on keyboard focus (`:focus-visible`).

In Figma, implement the focus ring as an overlay frame placed around the button component, not as a property of the button itself.
