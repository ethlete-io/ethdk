# A base branch with two hours of work gets a stand-in

On 18.11. almost all fifagg-frontend work ran directly on `next`. A base branch opens no stand-in, so the big blocks at
09:30 and 13:45 stayed "Not yet named", and they would on every such day. Recommended: open a stand-in anyway from 2 h
observed work on a base branch, named from the day's commits. The human: "q1 ok".

From 2 h observed work on a base branch in one day, Timetrack opens a stand-in for it, named from that day's commits on
the branch. Below 2 h nothing changes.
