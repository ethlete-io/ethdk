# @ethlete/cli

Release tooling for Changesets-based repos - installs the `et` binary.

## Installation

```bash
yarn add --dev @ethlete/cli
```

## Usage

```bash
yarn et release
```

Turns pending changesets into a tagged, pushed release commit (version → tag → commit → push).
