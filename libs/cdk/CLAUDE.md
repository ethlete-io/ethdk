# @ethlete/cdk — MAINTENANCE MODE

**Do not add new features to this library.** `@ethlete/cdk` is frozen for new
functionality — new features belong in **`libs/components` (`@ethlete/components`)**,
the active UI library.

**Bug fixes are fine here.** If a fix also applies to `components`, apply it there
too — most code here has an equivalent (often more evolved) under
`libs/components/src/lib/`.

Rule of thumb: fixing existing behaviour → OK in `cdk`; adding new behaviour/API →
do it in `libs/components`.
