A mock replaces the request, so it answers a route that has never run - or does not exist yet. It bypasses the interceptor chain by construction, so a mocked secure route never exercises the token flow. The library is kept; whether a mock is armed is not, so a reload always stops serving them. GraphQL queries are not offered: they all POST one route, so matching them needs the document rather than the path.
