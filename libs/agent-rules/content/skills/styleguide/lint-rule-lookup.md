# Lint rule lookup

Read this file only to explain a lint result or identify which rule owns a mechanical
convention. Run lint with `--fix`; do not hand-check this table before linting.

| Convention                                                           | Rule                                                                                                                                                                                                                |
| -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| No `any` / `$any()`; narrow `unknown`                                | `@typescript-eslint/no-explicit-any`, `@angular-eslint/template/no-any`                                                                                                                                             |
| Static strings and booleans use attributes                           | `@angular-eslint/template/prefer-static-string-properties`, `ethlete/prefer-static-boolean-properties`                                                                                                              |
| `type`, not `interface`                                              | `@typescript-eslint/consistent-type-definitions`                                                                                                                                                                    |
| No `enum` or `const enum`                                            | `ethlete/no-enum`                                                                                                                                                                                                   |
| `const` by default; one declaration per statement                    | `no-var`, `prefer-const`, `one-var`                                                                                                                                                                                 |
| Strict equality                                                      | `eqeqeq`                                                                                                                                                                                                            |
| Maximum two positional parameters                                    | `max-params`                                                                                                                                                                                                        |
| No type-only imports                                                 | `ethlete/no-type-only-import`                                                                                                                                                                                       |
| Descriptive `T`-prefixed generic names                               | `@typescript-eslint/naming-convention`                                                                                                                                                                              |
| No `async` / `await`                                                 | `ethlete/no-async-await`                                                                                                                                                                                            |
| Arrow functions standalone; methods in classes                       | `no-restricted-syntax`                                                                                                                                                                                              |
| Blank line before a multiline guard return                           | `ethlete/guard-return-newline`                                                                                                                                                                                      |
| No trivially inferable return type                                   | `ethlete/no-trivial-return-type`                                                                                                                                                                                    |
| Member and local naming conventions                                  | `@typescript-eslint/naming-convention`, `ethlete/no-leading-underscore-class-member`, `ethlete/no-screaming-case-local`                                                                                             |
| Class constants are `readonly` and upper case                        | `ethlete/class-constant-property`                                                                                                                                                                                   |
| No `readonly` on reactive members                                    | `ethlete/no-readonly-signal`                                                                                                                                                                                        |
| Injected and template-visible member accessibility                   | `ethlete/inject-member-accessibility`, `ethlete/template-member-accessibility`                                                                                                                                      |
| No inject chains, pure aliases, or trivial wrappers                  | `ethlete/no-inject-chain`, `ethlete/no-member-alias`, `ethlete/no-trivial-wrapper-method`                                                                                                                           |
| No unused private or protected members                               | `ethlete/no-unused-class-member`                                                                                                                                                                                    |
| Pure module-scope provider calls                                     | `ethlete/no-impure-top-level-provider`                                                                                                                                                                              |
| No redundant `@internal`                                             | `ethlete/no-redundant-internal`                                                                                                                                                                                     |
| Observable names end in `$`                                          | `ethlete/require-dollar-suffix`                                                                                                                                                                                     |
| No subscribe body, subscribe in pipe, or RxJS in signal derivations  | `ethlete/no-subscribe-with-body`, `ethlete/no-subscribe-in-pipe`, `ethlete/no-rxjs-in-effect`                                                                                                                       |
| Effect teardown uses `onCleanup` or `DestroyRef`                     | `ethlete/no-effect-cleanup-return`                                                                                                                                                                                  |
| Prefer `linkedSignal` for writable derived state                     | `ethlete/prefer-linked-signal`                                                                                                                                                                                      |
| Global component CSS encapsulation                                   | `ethlete/require-view-encapsulation-none`                                                                                                                                                                           |
| Angular-version-correct change detection metadata                    | `ethlete/require-on-push-change-detection`, `ethlete/no-redundant-on-push-change-detection`                                                                                                                         |
| No redundant standalone flag or empty metadata arrays                | `ethlete/no-standalone-flag`, `ethlete/no-empty-angular-metadata-arrays`                                                                                                                                            |
| No legacy lifecycle hooks or decorators                              | `no-restricted-syntax`, `ethlete/no-legacy-angular-decorators`                                                                                                                                                      |
| No injectable services, guards, or resolvers                         | `no-restricted-syntax`                                                                                                                                                                                              |
| Output naming                                                        | `@angular-eslint/no-output-on-prefix`, `@angular-eslint/no-output-native`, `ethlete/prefer-present-tense-output`                                                                                                    |
| Inputs do not collide with global HTML attributes                    | `ethlete/no-native-html-input-name`                                                                                                                                                                                 |
| No pipe logic                                                        | `ethlete/no-pipe-logic`                                                                                                                                                                                             |
| Class members and decorator metadata stay ordered                    | `ethlete/class-member-order`, `ethlete/angular-decorator-property-order`                                                                                                                                            |
| Routing views use `-view` / `ViewComponent`                          | `ethlete/enforce-routing-view-naming`                                                                                                                                                                               |
| No direct browser globals, DOM queries, native observers, or cookies | `no-restricted-globals`, `ethlete/no-direct-dom-manipulation`, `ethlete/no-dom-query`, `ethlete/no-native-observers`, `ethlete/no-document-cookie`                                                                  |
| No barrel imports                                                    | `no-restricted-syntax`                                                                                                                                                                                              |
| Prefer the SDK wrappers for platform utilities                       | `ethlete/prefer-clone-equal`, `ethlete/prefer-rxjs-timer`, `ethlete/prefer-match-media`, `ethlete/prefer-viewport-size`, `ethlete/no-angular-seo-services`, `ethlete/no-locale-id`, `ethlete/no-angular-router-api` |

Judgment still belongs outside lint: name things after their behavior, use an object
parameter after two positional parameters, expose injected members directly instead of
aliasing them, and use `/** @internal */` only on technically public library API that
must be stripped from declarations.
